# Risks

| ID | Risk | Likelihood | Impact | Mitigation | Steps |
|----|------|------------|--------|------------|-------|
| RISK-1 | Collection patches lose comments, commas, unknown members or defaults | High | High | Token-level fixture tests for edit/move/delete/orphans/BOM/partial sections; stop before UI wiring if preservation or effective default semantics fails; ask user instead of weakening guarantee | 1.1, 3.1, 5.1 |
| RISK-2 | Hotkeys/hooks/logging fail after persistence and old runtime cannot recover | Medium | High | Typed outcomes, owner-aware preflight, partial-resource teardown, guarded old-byte restore and previous config activation; distinguish partial recovery persistently. Stop integration if injected recovery faults leak hooks or report success | 2.1, 2.2, 5.1, 5.3 |
| RISK-3 | External edit races save/recovery | Medium | High | Compare exact bytes immediately before replacements; refuse newer file on recovery; keep backup and explain diverged disk/runtime. Final compare/replace race explicitly accepted, not falsely claimed solved | 1.1, 2.1, 5.1 |
| RISK-4 | Existing defaults/coercions/warnings differ from save semantics | High | Medium | Inspect current model/loader/schema; explicit shared rule adapter and separate advisories; test disabled and partial/null sections, key trimming and separate macro-file issues. Stop for scope decision if enforcing a new rule changes valid existing runtime behavior beyond Settings | 1.1, 3.2, 3.3, 4.2, 4.3 |
| RISK-5 | Apply interrupts macro activity or uses resources after logger disposal | Medium | High | Idle guard and serialized commands; captured old/candidate config; controlled ownership of logger/windows/hooks/services; preserve runtime toggles; no unrelated coordinator rewrite | 2.1, 2.2, 5.1 |
| RISK-6 | Focused capture conflicts with system shortcuts/layout/dead keys or logs input | Medium | Medium | No global capture hook; explicit capture/cancel state; physical VKey labels; supported keys/picker fallback; layout/repeat/Alt tests; adhere to HUD privacy contract | 3.1, 5.2 |
| RISK-7 | High DPI/work-area/native automation cannot be observed on execution host | Medium | Medium | Test layout/automation then human live matrix on supported display; record unverified rows; stop release completion if required matrix or genuine runtime registration cannot run safely | 5.2, 5.3 |
| RISK-8 | Isolated test seam still writes real logs/macros/topology or claims user hotkeys | Medium | High | Confine all mutable paths, fixture hotkeys, explicit desktop safety check and cleanup only the test instance; stop before startup if isolation/hotkeys cannot be established | 5.1, 5.3 |
| RISK-9 | Crash between save and activation | Low | Medium | Atomic valid file plus backup; next startup loads saved state; no crash-durable rollback/journal guarantee. Report this limit; fault tests address handled failures only | 2.1, 6.1 |

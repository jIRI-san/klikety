# Risks

| ID | Risk | Likelihood | Impact | Mitigation | Steps |
|----|------|------------|--------|------------|-------|
| RISK-1 | UIA/provider or IPC hangs; cancellation only stops the wait | High | High | Owned helper, parent watchdog, bounded I/O/cleanup, kill-on-close job, MTA-only UIA. Test a genuinely blocked child and next-scan recovery. Stop if helper exit cannot be observed without blocking UI or accumulating processes. | 1.1, 3.1, 4.2 |
| RISK-2 | UIA capability/visibility/geometry is incomplete or misleading | High | High | Explicit candidate policy, typed root failures/partial scans, identity/state/point validation, grid fallback. IsOffscreen is not an occlusion guarantee. Stop on missing identity; omit with a diagnostic instead of inventing a point. Elevated/custom-drawn/remote surfaces remain documented limits. | 1.1, 2.1, 3.1, 4.2 |
| RISK-3 | Overlay focus or stale callback scans/acts on the wrong window | Medium | High | Pre-overlay root context across every lifecycle path, generation-bound requests, helper retirement, post-await guards, genuine foreground checks at dispatch. Stop if a resume path only knows the current overlay HWND. | 1.2, 3.2 |
| RISK-4 | Dense/nested UI floods hints or hides independent targets | High | Medium | Identity-based deduplication, explicit partial limits, stable pages, bounded retained targets, readable list fallback, nested-control fixtures. Do not deduplicate by equal names/rectangles or silently truncate rendered targets. | 2.1, 2.2, 4.2 |
| RISK-5 | Physical/DIP mismatch, negative origins, or label collisions mislead targeting | Medium | High | PerMonitorV2 helper and current overlay coordinate helpers; geometry and measured-WPF rendering tests at mixed DPI; keep label and target points separate. Stop if font-floor containment cannot be met; use paged list placement. | 2.1, 2.2, 4.2 |
| RISK-6 | New mode misses hardcoded mode lists, help, binding policy, or lifecycle resume | High | High | Update all current default/chord/migration/validation/help/factory lists, run impacted regressions, and cover non-QWERTY and every SessionManager transition. Do not rewrite unrelated mode architecture. | 1.2, 3.2 |
| RISK-7 | Worker works locally but is missing/broken in published release | Medium | High | Establish development packaging early, publish matching RID/self-contained worker into isolated folder, verify extracted artifact handshake with no SDK. Stop on a manual-copy or globally installed runtime requirement. | 1.1, 4.1, 4.2 |
| RISK-8 | Async validation loses modifiers, emits duplicate input, or records rejected actions | Medium | High | Typed pending intent, original modifier snapshot, exactly-once generation gate, hide-before-hit-test, validate-before-record, drag/recording-specific tests. Stop if a rejection can still call SendInput or RecordAction. A small validation-to-input race remains an explicit limitation, not an atomicity guarantee. | 3.1, 3.2 |

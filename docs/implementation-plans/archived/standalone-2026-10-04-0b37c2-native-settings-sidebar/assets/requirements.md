# Requirements

Test names below are planned observable evidence, not claims that the tests already exist.

| ID | Requirement | Acceptance Criteria | Phases/Steps |
|----|-------------|---------------------|--------------|
| REQ-1 | Native reusable sidebar and draft lifecycle | Real tray opens/focuses one window; seven pages, common-first/collapsed Advanced, dirty/revert/page-switch/Discard/close/quit behaviors; invalid draft retains input and error targets. `test:SettingsDraftTests` and `test:SettingsWindowTests` | 1.2, 2.2, 5.2 |
| REQ-2 | Full config editing with explicit data boundaries | Every current user-editable ConfigModel/nested value appears in coverage map and has round-trip/editor checks; configVersion/$schema read-only; no write to themes/macros.json/registry or new HUD enable flag. `test:SettingsCoverageTests` and `test:SettingsRoundTripTests` | 3.1, 3.2, 3.3, 4.1, 4.2, 4.3, 5.1 |
| REQ-3 | Shared validation without defaults-on-error | Strict candidate parse, null/duplicate/unsupported-version handling; existing migration before editable snapshot; malformed/future/missing-external file blocks save without defaults; binding matrix and numeric/color/enum validation target fields; LogGrid/slot lengths retain warnings/effective behavior, edited indicators obey schema bounds with untouched-legacy exception, named log levels/count >=1; changed theme reference validated, unchanged fallback/content warning advisory. `test:SettingsValidationTests` and `test:SettingsMigrationTests` | 1.1, 3.1, 3.2, 3.3, 4.1, 4.2, 4.3 |
| REQ-4 | JSONC and observed concurrent-edit preservation | Scalars, array moves/inserts/deletes, object member add/delete, missing sections preserve all comments/unknowns/untouched scalar spelling and BOM; removed-entry comments retained in section; no-op does not write; observed snapshot conflict rejects; replacement atomic with exact old-byte backup; injected I/O errors visible. New fragments may normalize indentation; last-check/replace race accepted. `test:SettingsConfigStoreTests` | 1.1, 3.1, 5.1 |
| REQ-5 | Save/apply and explicit best-effort recovery | Guard idle before write; serialize apply/reload/reset; captured-config activation covers main/scroll/macro registrations, theme/renderers, logger, active HUD appearance; preserves HUD enabled/scroll pause. Capture disk/runtime baselines independently; failed activation disposes partial resources, attempts each restoration, preserves original backup/draft, reports each outcome; no draft rebase until full success and no newer external file overwritten during rollback. `test:SettingsApplyTests` and `test:SettingsRecoveryTests` | 2.1, 2.2, 4.1, 4.2, 4.3, 5.1, 5.3 |
| REQ-6 | Readable physical key pickers and focused capture | Pickers show readable labels/stable VKey; focused key/shortcut capture, Escape cancel/focus-loss cancel, modifier-only/repeat handling; no global capture hook/logging; action row add/remove and ordered axis/slot operations preserve physical keys; duplicate/reserved/collision errors block save. `test:SettingsKeyEditorTests` | 3.1, 3.2, 4.1, 4.2, 5.2 |
| REQ-7 | Keyboard, accessibility and DPI usability | Complete edit/save/discard/error/close paths by keyboard across all seven pages; visible focus, label targets/automation names and announced status; no clipped actionable controls at 100/150/200% on >=1280x720 DIP work area; resizing/scroll retains footer/access to advanced controls. Managed contracts remain required. Remaining genuine all-page interaction/announcement and DPI observations are user-owned deferred verification, not passing evidence, per the 2026-10-08 intent correction. `test:SettingsWindowTests` and `test:SettingsAccessibilityTests` | 1.2, 3.1, 3.2, 3.3, 4.1, 4.2, 4.3, 5.2, 5.3 |
| REQ-8 | Production verification and accurate documentation | Focused fake/file fault tests plus observed actual isolated native registration/apply/recovery demonstration, fixture-only paths/hotkeys; document configured vs runtime-only/separate-file controls, JSONC formatting/race, recovery limitations and each user-owned deferred native row. Unavailable input-dependent scroll/macro/HUD/tray/conflict-control and keyboard/DPI rows do not block finalization under the explicit 2026-10-08 user decision; no other evidence or safety requirement is waived. No production AppData mutation by automation. `test:SettingsIsolationTests` and `file:docs/design-notes/settings.design.md#exists` | 5.1, 5.3, 6.1 |

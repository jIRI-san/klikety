# Requirements

Acceptance criteria approved through whole-plan confirmation on 2026-10-07. Test names are planned evidence, not existing passing tests. Numeric budgets/defaults are recorded in `decisions.md`.

| ID | Requirement | Acceptance Criteria | Phases/Steps |
|----|-------------|---------------------|--------------|
| REQ-1 | Foreground-root detection | `test:ElementHintsCoordinatorTests`: scan HWND captured before overlay Show, never the overlay/desktop root; root descendants clipped to current ActiveBounds/navigation display; zero/destroyed/minimized roots and display changes have explicit outcomes. | 1.1, 1.2, 4.2 |
| REQ-2 | Meaningful interactive candidates | `test:ElementHintCandidatePolicyTests`: include known enabled buttons, edit/readonly edit focus targets, links, toggles, selections, expanders, combo/tab/list/tree/data items, and pattern-advertising custom controls; exclude passive text/focusable containers, disabled/offscreen elements, invalid bounds, own-process UI, and duplicate identity without merging independent targets. | 1.1, 2.1, 4.2 |
| REQ-3 | Bounded, truthful discovery | `test:UiaWorkerSupervisorTests`, `test:ElementHintCandidatePolicyTests`: proposed 1500 ms total scan deadline includes startup; 20000 visited nodes, depth 64, and 2000 retained targets; hitting a traversal/target cap marks partial results with a reason. Timeout, access denial, root/provider failure, and no targets are distinct from complete success. No UI-thread UIA or blocking process wait. | 1.1, 2.1, 4.2 |
| REQ-4 | Stable keyboard labels and reachability | `test:ElementHintsStateMachineTests`, `test:ElementHintLabelTests`: unique horizontal-first/vertical-second labels per page; every retained target selectable when count exceeds pair capacity; deterministic pages, prefix replacement, invalid-key feedback, selection without click, Escape unwind/cancel, Left/Right paging, and no action without selection. Redraw/layout refresh preserve VKey assignments and state. | 1.2, 2.2 |
| REQ-5 | Readable, correct geometry | `test:ElementHintGeometryTests`, `test:ElementHintLayoutTests`, `test:ElementHintRenderingTests`: finite/clipped physical geometry; window-origin-relative DIP rendering at 100/150/200% DPI and negative display origins; labels fit without text clipping at configured MinLabelFontSize; readable paging/list fallback instead of hidden targets; moving labels does not move action points. | 2.2, 4.2 |
| REQ-6 | Existing physical actions after selection | `test:ElementHintsStateMachineTests`, `test:ElementHintActionValidationTests`: selection emits no click; existing action bindings dispatch LeftClick/RightClick/DoubleClick/MiddleClick/MoveOnly/DragDrop through existing mouse service, with modifiers captured before async wait, exactly once; no UIA Invoke/SetValue/SetFocus. Existing grid quick actions remain unchanged. | 1.2, 3.1, 4.2 |
| REQ-7 | Fresh target validation before input | `test:ElementHintActionValidationTests`: proposed 500 ms validation deadline; overlay host hidden before hit testing; current HWND/root/element identity, state, unchanged geometry, region, and point ownership checked; stale/covered/disabled/destroyed/lost-foreground/timeout targets receive no input or recorded step. No safe point produces explicit rejection. A late result from an old activation cannot act. | 3.1, 4.2 |
| REQ-8 | Preserve all session integrations | `test:ElementHintsLifecycleTests`, `test:ElementHintsCoordinatorTests`: help preserves selection and dismiss-and-forward behavior; mode lock does not block explicit grid fallback; display/scope/drag/recording/picker/playback resume have correct target context; hint status does not erase macro/drag prompts; default-mode and non-QWERTY activation work; teardown/layout redraw never starts stray scans or input. | 3.2, 4.2 |
| REQ-9 | Opt-in, validated configuration and grid fallback | `test:ElementHintsConfigTests`: migration version 9 adds disabled settings idempotently, preserving user/unknown fields; shared schema/default merging and every binding conflict surface include the mode; invalid explicit settings disable its runtime dispatch with an actionable violation. Enabled mode requires UniformGrid, label/page controls, and exactly-one-default consistency. Enter switches to grid during scan, failure, prefix, selection, and lock without an implicit click. | 1.2, 3.2, 4.1 |
| REQ-10 | Owned bounded helper/protocol and privacy | `test:ElementHintProtocolTests`, `test:UiaWorkerSupervisorTests`: one owned helper; supported protocol version/IDs and finite geometry; request/response/stderr byte caps; missing/crashed/malformed child rejected; cancellation/shutdown/crash cleanup and repeat recovery; proposed 500 ms kill/exit cleanup deadline. UIA references remain helper-local; no captured values/password/document text or tree dumps in IPC/logs; no shell launch or UIAccess/elevation. | 1.1, 2.1, 3.1, 3.2, 4.1 |
| REQ-11 | Reproducible shipped helper | `test:ElementHintPackagingTests`: development build/run and self-contained win-x64 publish contain the worker executable plus runtime/dependency files in the expected isolated subfolder; extracted release runs its versioned handshake without an SDK. Missing helper makes this mode unavailable visibly while grid startup remains usable. | 4.1, 4.2 |
